くらしの選び方ガイド｜公開前セットアップ

1. index.html をブラウザで開いてデザインと記事を確認します。
2. about.html の「運営者名」「連絡先」を実際の情報へ変更します。
3. 無料公開なら GitHub Pages / Cloudflare Pages / Netlify 等へフォルダの中身をデプロイします。公開URLを控えます。
4. A8.net・もしもアフィリエイト等に公開URLを登録し、本人名義の振込口座を設定します。事前に広告掲載可否・審査基準を確認します。
5. 各広告主のプログラムへ提携申請。承認後に「広告リンク」を発行します。
6. affiliate-links.js の対応カテゴリの空文字 "" を発行済み正規広告URLに置き換え、ファイルを再アップロードします。
   例: internet: "https://（ASPから発行された正規リンク）"
   ※ URLを自分で改造しない、承認前の広告として表示しない。
7. policy.html を実際に利用するASP・解析ツール・Cookieに合わせ更新。
8. 独自ドメイン運用ならサイトマップと canonical、Search Console を設定。掲載情報を月1回点検。

【重要】
これは公開可能な静的サイトの初期版です。サーバー公開、ASP登録、本人確認、銀行口座の登録、提携審査は本人が実施する必要があります。
現時点で成果報酬リンクは未設定です。SEO流入・収益は保証されません。
検索上位を狙うには、実体験・独自写真・最新の一次情報を加えた記事の継続的な改善が必要です。
銀行口座や個人情報をこのHTMLサイトに埋め込まないでください。口座情報は各ASPの安全な登録画面で直接設定してください。
